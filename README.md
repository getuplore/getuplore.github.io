# Uplore

The Uplore home page: one place for every subject, for the whole family.

- Live at https://getuplore.github.io/
- **Maths** (Pip Maths) lives in its own repository, [getuplore/maths](https://github.com/getuplore/maths), served at https://getuplore.github.io/maths/
- English, Computers and French are coming.

Learners, progress and the family sign-in are shared with every subject automatically, because all pages are on the same web address.

The page is a single file (`index.html`) with no build step.
